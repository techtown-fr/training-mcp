# training-mcp

Demos MCP pour les formations TechTown.

| Dossier | Stack | Transport | Révision MCP |
|---------|-------|-----------|--------------|
| [`java-simple-demo/`](java-simple-demo/) | Spring Boot 4.1.1 + MCP SDK 2.0.1 | Streamable HTTP stateless (`/mcp`) | 2025-11-25 |
| [`python-simple-demo/`](python-simple-demo/) | FastMCP 4.0.2 | Streamable HTTP / STDIO | 2026-07-28 |
| [`spring-simple-demo/`](spring-simple-demo/) | Spring Boot 4.1.1 + Spring AI 2.0.1 | STDIO (GéoCalc) | 2025-11-25 |

Le SDK Java stable (2.0.1) et Spring AI 2.0.1 ne parlent pas encore **2026-07-28**. FastMCP 4 le fait, en restant compatible avec les clients legacy.

Inspector : `@modelcontextprotocol/inspector@2` (dernière 2.x).

Voir le README de chaque dossier pour build et usage.
